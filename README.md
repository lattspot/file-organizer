# 📂 파일 자동 정리 스크립트 (File Organizer)

"새 폴더 (2)", "이것저것"처럼 파일이 마구 섞여 있는 폴더를 **명령어 한 줄로 카테고리별 자동 정리**해 주는 파이썬 스크립트입니다.

개발자가 아닌 마케터가 AI(Claude)와 함께 만들었습니다. 코딩을 몰라도 따라 할 수 있도록 설명을 최대한 쉽게 적었어요.

---

## ✨ 주요 기능

- **확장자 기준 자동 분류**: 문서, 스프레드시트, PPT, 이미지, 동영상, 오디오, 압축파일, 코드, 설치파일
- **미리보기 모드**: 실제로 옮기기 전에 어떤 파일이 어디로 갈지 먼저 확인
- **되돌리기(`--undo`)**: 결과가 마음에 안 들면 원래 상태로 복구
- **날짜별 정리(`--by-date`)**: 카테고리 안에 `2026-10` 같은 월별 폴더까지 생성
- **이름 충돌 방지**: 같은 이름의 파일이 있으면 `파일명 (1).pdf`처럼 자동으로 이름을 바꿔 저장

## 📁 정리 결과 예시

```
정리 전                      정리 후
이것저것/                     이것저것/
├─ 보도자료.docx              ├─ 01_문서/
├─ 매출현황.xlsx              │   └─ 보도자료.docx
├─ 행사사진.jpg               ├─ 02_스프레드시트/
├─ 제안서.pptx                │   └─ 매출현황.xlsx
└─ setup.exe                 ├─ 03_프레젠테이션/
                             │   └─ 제안서.pptx
                             ├─ 04_이미지/
                             │   └─ 행사사진.jpg
                             └─ 09_설치파일/
                                 └─ setup.exe
```

버전 번호(예: `Python 3.12.0`)가 나오면 준비 완료입니다. Mac은 `python3 --version` 을 입력하세요.

## 🚀 사용법

### 1단계. 스크립트 다운로드

이 저장소의 `organize_files.py` 를 클릭한 뒤, 오른쪽 위의 다운로드 버튼을 눌러 내려받으세요.

### 2단계. 터미널 열기

- **Windows**: 시작 메뉴에서 `PowerShell` 검색 후 실행
- **Mac**: `터미널(Terminal)` 앱 실행

### 3단계. 미리보기 실행 (파일은 아직 옮겨지지 않아요)

```
python "스크립트 경로" "정리할 폴더 경로"
```

예시 (Windows):

```
python "C:\Users\내이름\Downloads\organize_files.py" "C:\Users\내이름\Desktop\이것저것"
```

> 💡 **경로 입력 꿀팁**: 경로를 직접 타이핑하지 말고, 파일이나 폴더를 터미널 창에 **끌어다 놓으면** 정확한 경로가 자동으로 입력됩니다.

### 4단계. 실제로 정리하기

미리보기 결과가 괜찮으면, 같은 명령 **끝에** `--apply` 를 붙여 실행하세요.

```
python "C:\Users\내이름\Downloads\organize_files.py" "C:\Users\내이름\Desktop\이것저것" --apply
```

> 💡 키보드 **위쪽 화살표(↑)** 를 누르면 방금 실행한 명령이 다시 나옵니다. 그 끝에 ` --apply` 만 덧붙이면 돼요.

### 되돌리기

```
python "스크립트 경로" "정리한 폴더 경로" --undo
```

## ⚙️ 옵션 정리

| 옵션 | 설명 |
|------|------|
| (없음) | 미리보기만 보여줌. 파일은 그대로 |
| `--apply` | 실제로 파일을 카테고리 폴더로 이동 |
| `--by-date` | 카테고리 안에 연-월(예: `2026-10`) 폴더까지 생성. `--apply` 와 함께 사용 |
| `--undo` | 마지막으로 정리한 내용을 원래대로 되돌림 |
